# Сканер funding-арбитража

Бот ищет связки для заработка на ставке финансирования (funding rate) бессрочных фьючерсов
на **Binance, Bybit, OKX, WhiteBIT**. Это **первый этап**: сканер только читает публичные данные.
API-ключи не нужны, сделок он не совершает.

## Как это работает

Каждые 1–8 часов на бессрочных фьючерсах держатели позиций обмениваются платежом:

- **funding > 0** — лонги платят шортам;
- **funding < 0** — шорты платят лонгам.

Если открыть две противоположные позиции на одну и ту же сумму, изменение цены не влияет на результат (позиция дельта-нейтральна), а funding вы получаете.

| Стратегия | Что делаем | Плюсы | Минусы |
|---|---|---|---|
| **1. Спот + шорт фьючерса** (одна биржа) | Покупаем монету на споте и шортим столько же на фьючерсе | Просто, риск ликвидации минимален | Работает только при funding > 0 |
| **2. Фьючерс против фьючерса** (две биржи) | Шортим там, где ставка выше, и лонгуем там, где ниже | Доход выше, работает и при отрицательных ставках | Нужна маржа на двух биржах, есть риск ликвидации одной ноги |

**Для $500 советую начать со стратегии 1.**

## Установка

Нужен Python 3.10 или новее.

```bash
cd funding-arb
python -m venv .venv
# Windows: .venv\Scripts\activate
source .venv/bin/activate
pip install -r requirements.txt
```

## Запуск

```bash
python main.py            # один скан
python main.py --loop     # сканировать каждые 10 минут
python main.py -v         # показать подробности ошибок соединения
```

Все результаты дописываются в `data/opportunities.csv`. Через 1–2 недели работы в режиме `--loop`
по этому файлу будет видно, насколько стабильны найденные связки.

> Binance и Bybit блокируют некоторые страны (в том числе США), а также IP облачных серверов в этих странах.
> Если для биржи показано «нет данных», запустите с `-v` и посмотрите причину ошибки.

## Как читать таблицу

- **Ставка/день** — текущая ставка, приведённая к суткам. Биржи платят с разным интервалом (1, 4 или 8 часов), сканер это учитывает.
- **Ср. за историю/день** — средняя ставка за последние 21 выплату.
- **APR брутто** — годовая доходность на номинал без комиссий, по текущей ставке.
- **APR на капитал** — годовая доходность на **ваши $500** после всех 4 комиссий (вход и выход по каждой ноге).
  Считается консервативно: по меньшей из двух ставок, текущей и средней.
- **Прибыль за N дн.** — ожидаемый доход в $ за срок `hold_days` после комиссий.
- **Разница цен** — базис между ногами. Плюс означает, что шортите дороже, чем покупаете, и вход выгоднее.
- **Оценка истории**: «стабильно» — ставка держится; «всплеск» — текущая ставка намного выше средней и,
  скорее всего, упадёт; «история против» — в среднем ставка была не в вашу пользу.

## Настройки — `config.yaml`

Главные параметры: `capital_usd`, `hold_days`, `perp_leverage`, `min_net_apr`, фильтры объёма.
**Обязательно укажите свои комиссии.** Скидка за BNB/OKB или VIP-уровень заметно меняет результат.

## Двигатель: запуск и команды

Движок (`engine/`) — бот, который работает круглосуточно: раз в минуту собирает данные со всех
наблюдаемых бирж, начисляет выплаты funding по открытым связкам, ищет новые связки и предлагает их
(режим `semi`) или открывает сам (режим `auto`). Раз в 30 секунд он проверяет запас до ликвидации и
перекос ног, раз в 10 минут сверяет позиции с брокером. Сейчас торговля только **виртуальная**
(`engine.virtual: true`): ордера исполняются по живым стаканам, но деньги ненастоящие.
Настройки — секция `engine` в `config.yaml`.

```bash
python -m engine run             # запустить бота; Ctrl+C — остановить
python -m engine status          # капитал, P&L за день и всего, funding, связки с запасом до ликвидации
python -m engine proposals       # предложения, которые ждут подтверждения
python -m engine approve 12      # подтвердить предложение №12 (лимиты проверяются ещё раз)
python -m engine reject 12       # отклонить предложение №12
python -m engine close 3         # закрыть связку №3
python -m engine stop            # закрыть ВСЕ связки и поставить бота на паузу (спросит «да»)
python -m engine pause           # пауза: новые связки не открываются, открытые охраняются
python -m engine resume          # снять паузу
python -m engine --config other.yaml status   # другой файл настроек
```

- Бот (`run`) должен работать в отдельном окне или на сервере. Команды `approve`, `reject`, `close`,
  `stop`, `pause`, `resume` только записывают команду в базу — бот выполнит её за пару секунд.
- Предложение действует 15 минут (`limits.proposal_ttl_s`), потом истекает.
- Журнал пишется на экран и в `data/shio.log`, база — `data/shio.db`.

## Telegram: подключение

Бот присылает предложения связок с кнопками «Открыть» / «Пропустить», тревоги, ежедневную сводку и
принимает команды `/status`, `/positions`, `/pause`, `/resume`, `/stop`, `/help`. Отвечает он
только вам: сообщения от других чатов игнорируются.

1. В Telegram найдите @BotFather, отправьте `/newbot` и получите токен бота.
2. Задайте токен в переменной окружения (в `config.yaml` токен не хранится):
   `export SHIO_TELEGRAM_TOKEN=123456:ABC...`
3. Узнайте свой `chat_id`: `python -m engine telegram-id`, затем напишите боту любое сообщение.
   Команда ждёт до 2 минут, печатает «Ваш chat_id: ...» и завершается. В Telegram она ничего не отвечает.
4. В `config.yaml` впишите `telegram.chat_id` и поставьте `telegram.enabled: true`.
5. Запустите `python -m engine run` и отправьте боту `/status`.

Если токена нет или Telegram недоступен, движок работает дальше, а уведомления идут в журнал
(в журнале будет предупреждение «Telegram не настроен: ...»).

## Реалистичные ожидания при $500

- В спокойном рынке funding по крупным монетам около 0,01% за 8ч, это примерно 11% годовых брутто.
  После комиссий за вход и выход при коротком удержании прибыль почти нулевая.
- Высокие ставки (50–200%+ годовых) бывают на альтконах во время хайпа. Там выше риски:
  низкая ликвидность, резкие движения цены, ставка может развернуться.
- Комиссия за круг (4 сделки) составляет около 0,3% номинала. **Держать позицию нужно дни, а не часы.**
- Реалистичная цель — **15–40% годовых**, то есть **$6–17 в месяц** с $500. Это способ научиться
  и проверить систему, а не источник дохода. Масштабировать стоит после того, как результат подтвердится.

## Риски

1. **Ликвидация фьючерсной ноги** при резком росте цены, если держите шорт с плечом. Плечо до 2x, следите за маржой.
2. **Ставка развернулась**: funding стал отрицательным, и вы начали платить. Выход стоит комиссий.
3. **Проблемы биржи**: заморозка вывода, делистинг монеты, банкротство.
4. **Неполное исполнение**: одна нога открылась, вторая нет.
5. **Налоги**: funding-доход обычно облагается налогом, уточните правила своей страны.
